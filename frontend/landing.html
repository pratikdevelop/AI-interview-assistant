Q: What is the virtual DOM and how does React use it for performance?
The virtual DOM is a lightweight JavaScript representation of the real DOM. When state changes, React creates a new virtual DOM tree, diffs it against the previous one using its reconciliation algorithm, and only updates the actual DOM nodes that changed — instead of re-rendering everything.
